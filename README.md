## Featured Projects

### Job Alert Automation Pipeline
Reads LinkedIn job alert emails, filters them by keyword, scores each role against a resume with an LLM, logs the matches to Google Sheets and emails a daily digest. It runs nightly on GitHub Actions. Built with AI assistance, it cut the noise in a personal job search so the best roles get attention first.

Tools: Python, Gmail API, Groq LLM, GitHub Actions. [View the repository](https://github.com/gauri-12/job_alert_pipeline_clean)

### E-commerce Data Analysis (SQL and Python)
Built a relational database from about 100K Kaggle orders, cleaned and transformed the data, and analyzed customers, orders, products, sellers and logistics. Health and beauty earned the most revenue, bed, bath and table sold the most items, and about 93% of orders arrived on time.

Tools: SQL, Python. [View the project](SQL_Project)

### Global Happiness and Socioeconomic Indicators
Combined Excel data, web-scraped tables and World Bank API data into one clean dataset. Happier countries tended to have longer life expectancy, higher GDP per capita and lower unemployment.

Tools: Python. [View the project](Python%20Data%20Wrangling)

### FBI NICS Firearm Background Check Analysis
Joined FBI background check data with U.S. Census data and found a strong link between state population and checks (r of about 0.85), with peaks in November and December.

Tools: Python. [View the project](Python%20EDA)
